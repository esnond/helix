# дизайн helix: рабочая палитра и экраны на все платформы

спека на замену v5 стиля для долгих рабочих сессий. принцип: интерфейс
инструмента не должен кричать; цвет несёт смысл только в трёх местах
(успех, предупреждение, опасность), всё остальное серо-зелёное и
спокойное. контраст всех текстов не ниже 4.5:1 (wcag aa).

## палитра

| токен | светлая | тёмная (по умолчанию) | смысл |
|---|---|---|---|
| bg | #f2f4ef | #14181a | фон приложения |
| surface | #fbfcf9 | #1c2124 | карточки, панели |
| ink | #26333c | #d7ddd6 | основной текст |
| mute | #6b7a72 | #8a958c | вторичный текст |
| accent | #4a7862 | #7fae94 | выделение, кнопки, ссылки |
| accent-press | #3a5f4d | #628e73 | нажатое состояние |
| ok | #4a7862 | #7fae94 | успех вывода ключа |
| warn | #a8813c | #c9a45c | предупреждения (не аудировано) |
| danger | #a04a42 | #c06a5e | ошибки, запрет перезаписи |
| hairline | #d5ddd2 | #2a3236 | линии, разделители |

правила: никакого чистого красного и чистого синего; danger темнее
привычного, чтобы аларм не бил по глазам; тёмная тема основная, светлая
для печати и документов; семантические цвета никогда не используются
как декор.

## типографика и форма

моноширинный шрифт для всего, что является данными: seed, dna карточки,
хэши, ключи (jetbrains mono / menlo / consolas стек). интерфейсный текст:
системный гротеск. радиусы 10 px, скругление без теней, границы 1 px
hairline, глубина только у модальных окон.

## экраны

### cli (сегодняшний вид)

таблица результатов уже норм; добавить цвет через 16 цветов терминала,
никаких truecolor без проверки поддержки; `--no-color` и уважение
NO_COLOR. ок/предупреждение/ошибка печатаются теми же тремя токенами
палитры.

### desktop gui

одно окно, три вкладки слева: seed, vault (.dna), evolution. справа
детали выбранного элемента. seed вводится в textarea с моноширинным
шрифтом и счётчиком слов (12/15/24 подсвечивает ok, остальное warn).
кнопка генерации одна, главное действие, accent. история операций в
нижней панели, каждая строка: время, операция, хэш результата.
перетаскивание .dna файла на окно открывает vault.

### android

одна активность с bottom navigation: seed / vault / about. списки
карточками surface, tap разворачивает детали нижним листом. биометрия
(BiometricPrompt) перед раскрытием ключа, никаких ключей на экране
дольше 30 секунд: таймер затемняет поле. large text поддерживается
через системные настройки, тест на 200% масштабе обязателен.

## компоненты

- seed field: моноширинный, счётчик слов, вставка из буфера с
  предупреждением о буфере обмена.
- dna card: имя, формат v2/v3, kyber пометка, дата, кнопки open/export,
  экспорт всегда с подтверждением danger.
- key reveal: скрытый блок, раскрытие через биометрию/пароль, таймер
  авто-скрытия 30 s, кнопка копирования пишет в буфер и стирает его
  через 60 s, если платформа позволяет.
- evolution graph: траектория коннектома рисуется линией accent на bg,
  никогда не анимируется бесконечно (долгие сессии).

## что не менять

предупреждение о неаудированной криптографии остаётся на каждом
критическом пути, слово "prototype" в шапке about не убирается ни в
одной теме. палитра не отменяет честные надписи.
