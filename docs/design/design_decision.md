# design decision: «бумага» (final, 2026-10-31)

verdict by owner: из предложенных макетов наименее плохой — «бумага» (v1).
маскот (волк) вырезан полностью: «картинка собаки плохая, просто вырежи её».

## принято

- маскот: ОРИГИНАЛЬНЫЙ рисунок владельца, вырезанный из фото
  (helix-gui/assets/mascot.png, 1080×1080 c альфой; белый фон →
  прозрачность, штрихи в оригинальном кармине). clarifying verdict
  owner 31.10: «вырезать» = вырезать фотку и вставить, не перерисовывать.
  размещение: правый угол меню (20px) + фигура в панели очередей (~130px).
  в egui: include_bytes! + image crate → ColorImage.
- направление: «бумага» — светлая тёплая тема, ЧИСТЫЕ линии (никаких
  рисованных/мелковых/пунктирных эффектов).mac-пропорции как каркас
  композиции.
- палитра: бумага #f6f1e8 (фон), панель #fdfbf6, чернила #2b2622,
  приглушённый #7d7568, hairline #d8d0c0, акцент кармин #a83a4d
  (единственный хроматический цвет; 4.9:1 на белом, wcag 1.4.3 ok),
  ошибки #b3402f, успех — кармин же (двухканальность убрана).
- лого: спираль в квадратной рамке (вариант А, одобрен ранее). волк не
  в лого — он маскот интерфейса (см. выше).
- шрифты: PT Sans (ui, кириллица-first) + JetBrains Mono (данные).
- применяется к: desktop (обе полярности? нет — светлая «бумага»
  основная; тёмная полярность остаётся как вторичная из theme.rs),
  android (та же тема через общий код).

## отвергнуто (хронология решений owner)

1. v5 brass/teal тёмная (r5) — «уродливая»
2. «операторская» (laboratory/NAVI, фосфор, каналы CH·01-04) — отвергнута
3. aqua (mac os x гель) — «нет, всё же старая макось была лучше»
4. 1-bit system 6 (одобрен как база 30.10, лого А одобрен) — вытеснен
   «бумагой» после раунда с proteus-стилем; хром 1-бита в архив
5. proteus-рисованный стиль ×3 (бумага/доска/1-бит+волк) + волк-маскот —
   «дизайн плохой, картинка собаки тоже»; жив только вектор «бумаги»

## правило

любое изменение дизайна = новый макет → апрув owner → порт. фрирайв
запрещён (memory: gui-aesthetics-rejected).
