        Ввод

        Физический звук

        • затвор = контакт (тик через highpass) + негармоническая пластина (моды 1:2.76:5.4:8.9) + удар корпуса с задержкой 6 мс + вторичный контакт на +42 мс
        • линия = калибровка свипом полосового шума + пакетные ack; прогресс = резонансные burst'ы, ползущие по частоте; гул катушки 50/53.9 Гц, пока очередь жива
        • сбой = реле: AM-buzz 100 Гц на низком saw + глухой двойной контакт
        • все звуки идут через один convolver (металлическая коробка) и шину с компрессором: у семьи одно тело
        • джиттер с сидом (id задачи + bucket): машина та же, события чуть другие

        Команда Сонификация (Ctrl+K): звук ведёт огибающая активности симуляции — полоса шума дышит вместе с работой, пакеты на её пиках. По умолчанию выключена.

        Очередь и состояния

        Модалка спрашивает только сид-фразу; работа идёт фоном с прогрессом, причиной и отменой. Пустой каталог и сбой чтения имеют свои состояния с причиной и следующим шагом.

        Дендрит и насечка

        Узел = поколение, насечки = мутации, текущее залито латунью. Наведение на файл подсвечивает его поколение. Насечка у строки = файл на старом поколении: расшифровка честно пересчитает цепочку.

        Контракт данных

        Фронтенд говорит только с транспортом: {v,status,gen,chain[{g,fp,mut}],files[{name,size,gen,mtime,broken}]} — форма будущего helix gui --json.

        Демо

        Ctrl K: «пустой каталог», «сбой чтения», «восстановить». Расшифровка corrupted.dna показывает аварийное завершение с причиной.

        Input

        • J/K select · E encrypt · D decrypt · G new key · X seed
        • Ctrl K commands · ? help · Esc close. Mouse yields the same actions and the same space.

        Physical sound

        • latch = contact tick (highpass) + inharmonic plate (modes 1:2.76:5.4:8.9) + body thump delayed 6 ms + secondary contact at +42 ms
        • line = bandpass-noise sweep calibration + packet acks; progress = resonant bursts crawling in frequency; coil hum 50/53.9 Hz while the queue lives
        • fault = relay: 100 Hz AM buzz on a low saw + dull double contact
        • everything routes through one convolver (metal box) and a compressed bus: the family shares a single body
        • seeded jitter (job id + bucket): same machine, slightly different events

        Command Sonify (Ctrl+K): the sound is driven by the simulation's activity envelope — a noise band breathes with the work, packets on its peaks. Off by default.

        Queue and states

        The modal asks only for the seed phrase; work runs in background with progress, reason and cancel. Empty directory and read failure have their own states with cause and next step.

        Dendrite and notch

        Node = generation, notches = mutations, current one filled brass. Hovering a file highlights its generation. A row notch = file sealed at an older generation: decrypt will honestly re-derive the chain.

        Data contract

        The frontend talks only to the transport: {v,status,gen,chain[{g,fp,mut}],files[{name,size,gen,mtime,broken}]} — the shape of future helix gui --json.
